# 情侣互动游戏项目 - 项目概述

## 📖 背景

### 原项目分析
本项目基于开源项目 **Open Source Selfie Stick** 进行启发和代码复用。

原项目是一个 iOS 应用，功能是：
- 将两台 iPhone/iPad 通过 WiFi 或蓝牙配对
- 一台作为相机，另一台作为遥控器
- 远程控制拍照，照片可保存到两台设备
- 使用 Apple MultipeerConnectivity 框架实现设备通信

**原项目技术栈：**
- UIKit + Swift 2/3
- AVFoundation（相机控制）
- MultipeerConnectivity（设备通信）
- AssetsLibrary（照片保存）

**原项目代码文件：**
- `CameraServiceManager.swift` - 核心通信管理（可复用）
- `CameraViewController.swift` - 相机界面（不复用）
- `CameraControllerViewController.swift` - 遥控器界面（不复用）
- `AVCamPreviewController.swift` - 相机预览（不复用）

### 项目启发
从原项目的设备配对功能出发，我们思考了情侣/朋友间的有趣互动场景，最终确定了以下产品方向。

## 🎮 产品功能规划

### Phase 1: MVP（最小可行产品）

**核心功能：画画猜猜游戏**

**玩法流程：**
1. 两台设备配对连接
2. 系统给出相同题目（如"大象"）
3. 两人各自在手机上画，**看不到对方的画**
4. 30秒倒计时
5. 时间到，两幅画同时显示
6. AI 评分相似度："你们的默契度 87%"
7. 保存到历史记录

**为什么选这个作为 MVP：**
- ✅ 技术实现简单（基于原项目改造）
- ✅ 立刻能玩，马上有反馈
- ✅ 不依赖复杂 AI
- ✅ 情侣/朋友都能玩，受众广
- ✅ 容易传播（结果截图分享）
- ✅ 周末就能做出原型

### Phase 2: 功能扩展

**新增游戏模式：**

1. **接力画（异步协作）**
   - 一人画一笔传给对方
   - 对方接着画再传回来
   - 共同完成一幅画
   - 适合异地恋

2. **真心话大冒险**
   - 数字版经典游戏
   - 系统随机生成问题
   - 只有两人能看到
   - 记录有趣的回答

3. **同步涂鸦**
   - 两人同时在画布上画
   - 实时看到对方笔触
   - 协作完成创意作品

### Phase 3: 进阶功能

**双人拍照功能：**
- 一台做相机，一台做遥控+实时预览
- AI 自动抓拍最佳瞬间
- 双人美颜
- 情侣专属滤镜
- 社交化输出（九宫格、拼图）

**其他可能方向：**
- 更多小游戏
- AR 互动
- 情侣纪念日功能
- 照片/游戏历史相册

## 📊 与原项目的关系

### 本质区别

| 维度 | 原项目 | 新项目 |
|------|--------|--------|
| **定位** | 工具（虚拟自拍杆） | 娱乐/游戏 |
| **核心价值** | 解决拍照问题 | 提供互动体验 |
| **使用场景** | 拍照时使用 | 日常娱乐时刻 |
| **用户关系** | 任意两台设备 | 情侣/亲密朋友 |
| **内容产出** | 照片 | 游戏记录+照片 |
| **社交属性** | 弱 | 强（分享、回忆） |

### 代码复用策略

**直接复用：**
- MultipeerConnectivity 设备发现、配对、连接逻辑
- 数据传输、文件传输方法
- 设备管理相关代码

**需要改造：**
- UIKit → SwiftUI
- ObservableObject → @Observable macro
- 硬编码消息 → 通用消息模型
- 相机特定逻辑 → 游戏逻辑

**不使用：**
- 所有相机相关代码（AVFoundation）
- UI 界面代码
- 照片处理逻辑（Phase 1 不需要）
